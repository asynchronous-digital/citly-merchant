# Design System Rules

- Read `design-system/MASTER.md` before shared UI work.
- If a matching page doc exists in `design-system/pages/`, it overrides the master.
- Update design-system docs when UI behavior or presentation changes.

## Visual direction

- fixed sidebar + fixed topbar
- cool off-white canvas
- light glass chrome
- dense operational layout
- token-based colors only
